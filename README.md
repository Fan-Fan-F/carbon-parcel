# carbon-parcel · 包裹碳足迹计算器

零依赖（原生 HTML/CSS/JS + Canvas）的绿色物流工具：计算电商包裹从发货到收货的碳排放，对比不同运输方案的碳足迹差异。

## 功能

- **14 个国内主要城市**：大圆距离公式估算里程，叠加绕行系数（公路 ×1.2、铁路 ×1.15、海运 ×1.35、航空 ×1.05）
- **四种运输方式排放因子**（gCO₂e/吨·公里）：航空 602 / 公路 80 / 铁路 22 / 海运 12（参考 DEFRA 2023 与中国生命周期排放系数库）
- **包装排放模型**：纸箱 + 填充物 + 胶带，按包裹重量四档估算
- **三方案对比**：公路直达（标准快递）/ 铁公联运（经济件）/ 航空直达（特快），自动标注最低碳与最高碳方案
- **排放构成拆解**：分段运输 + 包装的占比条形图
- **生活化换算**：等效"几棵树一天的吸收量""手机充电次数""燃油车行驶公里"
- **时效-碳排权衡**：每种方案同时给出预计送达时长

## 核心结论

同样 2kg 包裹深圳→北京，航空约是铁公联运的 **8-10 倍**碳排放——"慢快递"是最便宜的减碳方式。

## 计算模型

```
运输排放 = Σ(每段里程 × 重量(t) × 方式因子)
包装排放 = 纸箱 + 填充物 + 胶带（按重量档）
总排放   = 运输 + 包装，单位 gCO₂e
```
